## Werkzeuge für die Agenten-Sitzungen: Ponytail-Probe und 18 Agent Skills

Für die Sitzungen, die an diesem Repo arbeiten, gibt es zwei neue Werkzeuge — an der App selbst ändert sich nichts, nichts davon startet mit ihr. Erstens läuft vom 18. bis 25.09. eine Probe mit Ponytail, einem Regelwerk, das die Sitzungen zum kürzesten funktionierenden Code anhält (erst fragen, ob etwas gebaut werden muss, dann Vorhandenes und die Standardbibliothek nutzen, keine neuen Abhängigkeiten); die Regeln, die den Repo-Regeln widersprachen, sind gestrichen, und die Messbasis für den Vergleich nach einer Woche steht in `wiki/ponytail-probe.md`. Zweitens liegen 18 angepasste Arbeitsabläufe aus Addy Osmanis Agent Skills unter `.claude/skills/` (Spezifizieren, Testen, Fehlersuche, Sicherheit, Doku, Übergaben), aufrufbar als `/<name>` in Claude Code, jeder mit deutscher Ausgabe und dem Vorrang der Repo-Regeln; sieben Skills wurden mit Grund abgelehnt (`wiki/skills-uebernahme.md`).
