# Die Kosten-Freigabeschwelle zählt Tage und Marktlagen, keine Klicks

Die Kostenmessung am Demo-Konto zeigte bisher »n von ~20 Runden« an — eine
Schwelle, die sich mit zwanzig Klicks in zwei Minuten erfüllen ließ und dann
eine einzige Marktlage gemessen hätte (genau so entstanden die 16 vorhandenen
Aktienrunden am 25.08.). Nach Wilhelms Entscheid verlangt die Freigabe jetzt
Runden über verschiedene Tage UND Marktlagen. Jede neue Runde merkt sich dafür
die Marktlage (S&P 500 über/unter der 200er-Linie — derselbe Anker, den die
Regime-Zuteilung benutzt), und der Status nennt statt der Rundenzahl die
erreichte Streuung. Stand heute: 16 Aktienrunden an einem Tag, keine erfasste
Marktlage — die Schwelle ist nicht erfüllt.

Festgehalten als Zählregel im Code samt Test; ausdrücklich kein Taktgeber —
gemessen wird weiter nur von Hand, jede Runde ist eine echte Demo-Order.
